# Habit Hug

Build a simple habit tracker app. Users should be able to add habits, mark them as completed each day, and see a weekly streak view. Use a clean, minimal design with Tailwind CSS and shadcn/ui components. Include Supabase for authentication and data storage.

This project was built with an AI app builder.

## Build with the AI editor
